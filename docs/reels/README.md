# إصلاح الريلز — السبب والنتائج

## السبب الجذري (مُثبت بالفحص)
| المشكلة | الدليل | السبب |
|---|---|---|
| مربع أسود في شبكة الملف الشخصي | `profile_grid_before.jpg`، والإطار 0 متوسط سطوعه 0.0 | الفيديو يبدأ بتلاشٍ من الأسود (0.4 ث) والنص يظهر بعد 0.6 ث، والسكربت لا يرسل `cover_url` ولا `thumb_offset`، فيأخذ إنستغرام الإطار الأول (الافتراضي 0 ms) غلافاً |
| النص مخفي ومقصوص | `before.jpg` (لوحة IG UI) | التصميم منشور ثابت داخل فيديو: الصورة في المربع العلوي فقط، والنص من y≈1100 إلى y≈1870، أي داخل أسفل 35% الذي يغطيه الوصف واسم الحساب، وخارج قص الشبكة 3:4 (y 240–1680)، ويبدأ على بعد 70 بكسل من اليمين تحت أزرار الإعجاب |
| نهاية سوداء | blackdetect | تلاشٍ إلى الأسود في آخر 0.6 ث |
| مواصفات ناقصة | ffprobe + فحص atoms | SAR غير مضبوطة (N/A) وتوجد edit lists (`elst`) ووثائق Meta تطلب عدم وجودها |
| قص نص منشورات الصور في الشبكة | منشور الأخطبوط | الهامش الجانبي 34 بكسل = بالضبط ما تقصه الشبكة 3:4 من صورة 4:5 (33.75 بكسل لكل جانب) |

ما ليس سبباً: أبعاد الفيديو كانت صحيحة (1080×1920، H.264، yuv420p، 30fps، faststart)، ولا توجد حواف سوداء داخل الفيديو، وكان النشر فعلاً `media_type=REELS` وليس صورة.

## الإصلاح
- تصميم جديد بملء الشاشة: صور كاملة (قص cover بلا تمطيط) بحركة هادئة، مشهد افتتاحي «هل تعلم؟» + عنوان من أول إطار، تقسيم المعلومة إلى مشاهد بقياس تلقائي للخط، أرقام ذهبية، مشهد ختامي.
- كل النصوص داخل المنطقة الآمنة (يسار/يمين 120، أعلى 270، أسفل 672 بكسل)، والعنوان والغلاف داخل قص 1:1 و3:4.
- غلاف مستقل لكل ريلز يُرسل عبر `cover_url` (مدعوم في Graph API v26).
- `setsar=1`، بدون edit lists، faststart، H.264 High 4.1، AAC 48 kHz.
- فحص جودة إلزامي قبل النشر (`tools/validate_reel.py`)، ونشر آمن (منع التكرار، إعادة المحاولة، التحقق بعد النشر، الحالة لا تُحدَّث إلا بعد النجاح).

## الاختبارات
`test_summary.md` — سبع حالات، كلها نجحت على GitHub Actions بصور Pexels الحقيقية. المعاينات `after_*.jpg`،
و`after_next_real_spec_dry_run.jpg` تشغيل تجريبي (بدون نشر) على المعلومة التالية الفعلية في الطابور.
آخر معاينات تُرفق تلقائياً بالإصدار التجريبي `reel-previews` في صفحة Releases.

أثناء الاختبار على GitHub أوقف فحص الجودة فيديوهات بصيغة ألوان `yuvj420p` (نطاق كامل من صور JPEG)،
فأُصلح المخرج ليكون `yuv420p` بنطاق محدود BT.709 — دليل على أن البوابة تعمل.
